# 隐私与发布范围

## 包含

应用源码、完整数据库迁移、依赖版本、合成测试、CI、脱敏设计记录、本地初始化工具和服务器服务模板。

## 不包含

真实账号、密码、用户人物及关系档案、聊天记录、上传媒体、私人文档/Skills、API Key、加密密钥、两份真实 `.env`、生产数据库及 WAL/SHM、备份恢复包、生产日志和个人电脑/服务器专用传输脚本。

用户注册后分别设置自己的模型 API；部署者无需在公开配置内提供共享密钥。`.env.example` 只有空值和示例配置。第三方参考资料需要自行取得使用权限并在登录后上传。

本次整理检查当前发布文件树，把早期交接和验收现场记录替换为历史索引；没有复制私人工作目录或生产文件。已有 Git 历史仍保留，当前文件脱敏不等于从历史中抹除。若发现真实密钥曾被提交，需先撤销/轮换，再单独处理历史清理；不要把具体密钥贴在公开问题中。

`scripts/check_public_tree.py` 检查受版本控制的文件，并在 CI 中运行。它只能识别部分明显问题；发布前仍需确认新样例为合成内容，图片和文档无真实个人资料。

人物删除会清理当前应用中的关联数据和媒体；独立历史备份不会因此自动销毁，应按自己的备份保留策略处理。
