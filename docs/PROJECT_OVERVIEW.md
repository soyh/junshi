## 目录及功能

- backend/app：后端业务、网页、用户独立模型配置、参考资料检索及人物长期档案。
- backend/migrations：001–023。021 平台账号和会话来源，022 一次性网页登录交接；023 为邮箱身份、验证码、管理审计与附件清理任务，不改写历史迁移。
- backend/tests：专项、全量、浏览器验收。
- desktop：Windows 小窗源码、管理界面、打包和测试。
- android：独立 App、悬浮窗、分享附件、测试及构建说明。
- scripts：初始化、备份、恢复、发布文件检查。
- deploy/systemd：服务器服务与定时任务模板。
- docs：当前部署指南、设计记录与历史交接。
- .github/workflows：构建、验证与发布附件归档。

客户端通过 HTTPS 使用现有账号，业务数据保存在服务器。导入消息后生成建议，复制后实际发送，再确认登记自己的回复。模型密钥始终按用户隔离。

## 发布与运维边界

仓库更新不执行服务器部署。服务器升级先核对实际 SHA、隔离测试、数据库副本演练和最终备份，再按当前运维指南执行。历史阶段上线脚本含固定版本与环境参数，仅适用于原阶段，不作为通用部署入口。

用户数据、截图中的身份信息、私人参考文档、模型密钥、数据库、环境配置及日志不纳入公开附件。第三方文档的原始版权材料由用户自行管理。
