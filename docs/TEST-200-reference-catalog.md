# TEST-200：多文档目录与按需参考

基线：TEST-199 `a3b1341126cf0ae656b6fbe8f2dca76b3eccf4a6`。不新增迁移，不修改历史迁移、部署单元或依赖。

## 使用方法

已有的 Markdown 导读可以直接作为普通 Document 上传。目录文件及其引用的文档必须同时上传，并在当前会话启用。支持反引号文件名和 Markdown 链接，例如：

```markdown
# 参考资料导读
- 冲突与修复：`万能吵架技巧：理性冲突处理指南.md`
- 情绪回应：[回应指南](references/为他人提供情绪价值：温暖且有效的回应指南.md)
- 拒绝与边界：`高情商拒绝他人：体面护边界的实用指南.md`
```

路径仅用于匹配上传文件的 basename，不会访问服务器路径或下载外链。同名文件无法唯一匹配时会提示歧义；可以修改显示名称并在目录中使用唯一名称。停用或未上传的文件会提示未匹配。所有匹配均限制在当前用户、当前会话有效资料中。

点击“预览目录匹配与候选资料”查看本地预选、目录缺失文件和候选数量。这是本地预览，不是模型实际阅读记录。

## 请求过程与边界

1. 从当前会话最近 8 条消息构造最多 2400 字符的检索问题。
2. 本地扫描所有已启用文档的分段，包括文档尾部。文件名、目录主题映射及正文词项共同排序；中文使用双字词项，英文使用单词。这是轻量词项检索，不是 embedding 语义检索。
3. 候选目录最多 24 项，优先保留前 2 个 Skill 和前 2 个已识别导读；超出部分会明确计数。每个候选正文片段最多 1800 字符。Skill 优先保留开头方法指引，长 Skill 也会截取。
4. 使用当前所选兼容模型进行一次小型目录选择请求，最多选择 6 个 ID；仅向模型发送名称、主题、说明及最近聊天，不发送候选正文。另保留最多 2 个核心 Skill。
5. 正式分析/回复请求只带选中文件的片段，同一参考正文不在嵌套上下文中重复。无效 ID、格式错误或目录请求失败时回退本地预选。

目录选择通常会增加一次模型请求，产生额外延迟和少量费用。大量文件可以存储和检索，但不保证每次阅读全部文件；需要逐文档完整比较时，应另用分批分析流程。模型目录选择和本地检索均可能漏选，用户可通过当前会话启用范围及优先级调整。

## 长度预算与错误

`LLM_INPUT_BUDGET_TOKENS` 默认 32768，范围 4096–1000000；目前使用完整请求 JSON 的 UTF-8 字节数作为保守 token 上界估算，不是模型专用 tokenizer。计入提示词和结构化响应 schema。`LLM_OUTPUT_MAX_TOKENS` 默认 4096，范围 256–32768，用于输出预留。运营者应按所用模型的上下文容量设置输入加输出预算；系统不声称自动知道所有模型容量。

超过本地预算时先缩减参考内容，不静默删除聊天证据。参考内容缩减后仍过长则在请求前返回明确错误。供应商明确返回上下文超限时，至多缩减后重试一次；鉴权失败和限流不重试。鉴权、限流/额度、超时、网络、上下文超限和本地预算错误使用固定允许列表消息，不暴露供应商原始响应或 API 密钥。

测试使用模拟供应商，覆盖 DeepSeek/Qwen 兼容传输流程，不代表已经对用户真实账户进行付费模型调用。真实模型效果须在隔离验收后验证。
