# 本地安装与运行

入口命令见 [README](../README.md)。使用 Python 3.11 的独立虚拟环境；不要覆盖系统 Python。生产已使用 3.11.13，主分支 CI 使用 3.11 系列。Windows 无需激活虚拟环境或调整 PowerShell 执行策略，直接调用 `.venv\Scripts\python.exe` 即可。

## 首次安装

1. 克隆 `main`，安装 `backend/requirements.txt`。
2. 运行 `scripts/init_local.py`，它根据仓库位置写入绝对数据路径，生成本机加密密钥，并绑定 `127.0.0.1`。默认关闭调试和旧式 bootstrap 认证。
3. 在仓库根目录执行 `python -m app.server`。本文的 `python` 均指本项目虚拟环境里的解释器。
4. 打开 `/app`，注册账号。到模型设置填写自己的 API Key，测试连接后保存；不同账号分别配置。模型接口由客户端电脑上的后端访问，需有相应网络连接。
5. 新建人物并导入记录。时间按北京时间展示；批量导入先预览，再映射自己和对方。

本地安装是空白账号和空白数据。原服务器的聊天、人物摘要、用户配置和私有参考文档不会随 GitHub 克隆。需要旧数据时参照 [运维与恢复](OPERATIONS.md)，不要把数据库上传到 GitHub。

## 配置与持久化

| 路径 | 用途 |
| --- | --- |
| `.env` | 私有运行配置和加密密钥；初始化不打印密钥 |
| `backend/.env` | 旧部署的可选覆盖文件，优先于根目录配置；新安装不创建 |
| `data/app.sqlite3` | 账号、人物、聊天和业务数据 |
| `data/media/` | 上传的媒体文件 |
| `data/backups/` | 本机数据库备份 |
| `data/recovery_exports/` | 可移植加密恢复包 |
| `logs/` | 私有运行日志 |

系统环境变量优先于 `.env`。若启动使用了意外端口或路径，检查当前终端是否设置了同名变量。密钥丢失可能导致已保存模型凭据无法解密；不要重新生成密钥来处理普通启动错误。Windows 文件访问权限由当前用户的 NTFS ACL 管理，应安装在自己的用户目录，不要放在公共共享目录。

重启只需运行 `python -m app.server`，**不要再次初始化**。端口修改可编辑本机 `.env` 的 `PORT` 再重启。更换项目目录后需同步更新 `.env` 中的绝对路径。

## 健康检查与常见问题

浏览器打开 `http://127.0.0.1:18080/health/ready`，应显示 `ready` 且迁移数量为 20。登录页是 `/app`，根路径 `/` 不作为验收入口。

- 安装依赖超时：可自行选择可信的 PyPI 镜像，例如给 pip 添加 `--index-url https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple`；不关闭 TLS 校验。
- 端口已占用：更换本机 `PORT`，访问同一个新端口。SSH 本地转发端口与服务器端口可以不同。
- 模型报错：先测试当前用户的模型配置，再检查额度、模型名称及接口兼容性。不要粘贴 API Key 到 issue。
- 初始化拒绝：说明检测到配置或数据。保留现有文件，按升级或恢复流程处理，不要删除数据库来强行通过。
- 停止：在启动终端按 `Ctrl+C`。关闭终端后应用不继续提供服务。

此入口仅绑定本机。通过互联网访问需另行配置 HTTPS 反向代理和服务器安全设置，不能直接把本地端口开放到公网。

## Windows 双击启动

首次完成依赖安装和配置初始化后，双击项目根目录的 **Start-AI-Love-Strategist.cmd** 即可。可右键创建快捷方式放在桌面；不要只把 cmd 文件移出项目目录。

启动器自动定位项目目录，即使路径含空格也可运行。它使用项目自己的 `.venv`，读取实际 HOST/PORT，等待健康检查通过后打开 `/app`；不会自动安装依赖、更改配置或删除数据。已有正常服务时只打开页面，不重复启动。

若虚拟环境或配置缺失、端口被其他程序占用、服务启动失败，会保留错误窗口供查看。没有默认浏览器时可复制窗口中的地址手动访问。项目运行期间保留首次启动窗口；按 Ctrl+C 可停止该窗口启动的服务。

已安装的用户先在项目目录运行 `git pull --ff-only` 获取启动文件。如果原来克隆的是旧阶段分支或固定提交，先保留现有配置和数据，按升级说明核对版本，不要强行 reset。
