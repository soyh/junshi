# TEST-229：账号界面与用户目录

生产当前已验收版本为 TEST-228，数据库迁移 001–023。此变更无新增迁移。

- 网页邮箱管理弹窗沿用蓝白色按钮、输入框和投影，设置页底部入口保持小字样式。
- 管理员通过表格选择用户，不再手动输入 ID。支持账号、邮箱、ID 搜索，每页 20 位用户，显示总人数和翻页控件；目录包含所有用户，包括无登录账号名称的本地用户。
- 未选用户时禁用管理操作，永久删除确认显示目标账号与 ID。关闭窗口清除选择与敏感输入。查看、修改、删除仍要求管理员权限并保留原因和审计记录。
- PC 确认操作按钮复用主按钮样式；Android 邮箱弹窗复用统一主题。新版客户端为 PC 229 / Android 1.0.0-rc4（测试签名）。

## 全新安装

仓库包含后端、网页、Windows 客户端、Android 源码、迁移文件、部署脚本和说明。请按根目录 README 安装依赖、创建配置和初始化数据库。下载源码不包含现有用户、聊天、密钥或生产配置。

生产邮箱注册需配置 SMTP、验证码密钥和 EMAIL_REGISTRATION_REQUIRED=true。每个用户配置自己的模型 API；管理员用 scripts/account_admin.py 为现有账号授权。Linux 服务部署与 Windows 本地启动步骤见 README。Android 正式签名需自行配置，测试 APK 不等同于固定签名正式包。

## 验证

专项接口测试覆盖目录权限、完整分页、字面搜索和邮箱生命周期；浏览器测试覆盖手机/桌面、选择与翻页、恶意用户名的安全显示、关闭后清除选择。完整回归和客户端构建由该候选的 GitHub CI 验证。
