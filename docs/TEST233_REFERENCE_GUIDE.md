# TEST-233 完整目录与两层主题判断

当前为待服务器隔离验收候选。数据库新增 024，只新增主题指南标记；001–023 保持不变。

## 使用

上传资料后，在该文件的设置中勾选“设为主题指南”并保存。新建主题指南默认带此标记。已有资料默认保留自动识别兼容；手动指定后，以指定指南提取主题分类。文件引用仍检查其他已启用资料，错误会显示来源文件、行号和目标名称。

全局预览无需选择会话，列出完整资料清单、启用状态、主题与文件关联。会话预览遵循原有会话覆盖。文件名必须明确；“知识 11、12”这类简称请改为完整文件名。同名文件不会擅自合并。

## 模型流程

1. 根据近期对话，从指南的主题中选择最多三类，判断的是当前场景，不给人物永久贴标签。
2. 优先在命中主题的关联文件中选择最多六份资料，同时保留核心 Skill/指南及少量补充候选。
3. 仅将选中文件的相关片段送入实际回答请求，继续执行输入预算和最新聊天依据校验。

两层判断使用精简主题和目录，不读取所有正文。分类不明确、返回无效或失败时保留完整目录选择；目录超预算先压缩元数据，仍超预算则使用完整本地索引的排序结果。预览不能证明模型充分采用了每一条内容。

全部启用文件可参与检索，不再固定只保留前 24 项。正文仍按需截取，不承诺任意数量资料同时放入模型上下文。额外主题判断会增加一次小模型请求，供应商按实际请求计费；同一上下文的既有缓存仍可复用。

## 验证与升级边界

测试覆盖 44 项文件末尾可选、两层请求顺序、未选正文排除、指南权限、来源行号、会话覆盖及桌面/手机页面。旧账号导入包缺少 is_guide 字段时按 false 兼容，导出保留标记。

正式切换前必须运行服务器隔离全量及生产副本 023→024 演练，核对原有资料、聊天及配置。此候选不自动部署服务器。
