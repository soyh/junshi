# TEST-201：无需会话的全局主题指南

基线为 TEST-200 `f0bf037c269f033f29d4c5683a5fbf5b14f74d53`，不新增迁移或依赖。

“主题指南全文”不是要求上传的固定文件名，而是此前对导读文件正文的描述。目录文件是可选的：没有手写目录时，系统仍根据已启用资料的名称和正文生成候选目录。

## 操作

登录后进入“参考资料 / Skills”，不必选择会话：

1. 用“全局默认”作用范围启用所需文档和 Skill。
2. 点击“新建全局主题指南”。草稿自动列出当前账户全局启用的文件名；补充各文件适用主题，修改指南名称后保存。保存前不会创建空白文件。
3. 保存后指南作为普通 Markdown Document 全局默认启用，优先级为 10。后续可展开全文并在线编辑。
4. 点击“预览全局目录与候选资料”，检查文件匹配及缺失/歧义提示，无需选择会话。

全局是当前账户的资料默认值，不是跨账户共享。已有及新建会话默认继承；会话中的显式启用/禁用或优先级设置继续优先，不因本次改动被覆盖。若需要某个会话重新继承，可在该会话使用“恢复跟随全局”。真实聊天分析仍需要选定会话，以确定分析哪段聊天。

全局预览不使用任何会话的聊天内容，只检查全局启用资料及目录映射。真正分析时仍以当前会话的消息检索，并受 TEST-200 的长度预算约束。

新增接口：GET `/api/v1/references/catalog` 与 POST `/api/v1/references/guide`；均使用现有账户鉴权，新建文件不改变其他文档或任何会话覆盖设置。原在线编辑版本冲突保护保持有效。
